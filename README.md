# Movie Library - Личная кинотека

**Автор:** Виктория Кондратович

## Описание

Movie Library — это десктопное приложение для ведения личной коллекции фильмов. Программа позволяет добавлять, удалять, фильтровать и сохранять информацию о фильмах в формате JSON.

## Функциональные возможности

- Добавление фильмов с указанием названия, жанра, года выпуска и рейтинга
- Валидация данных (год - целое число, рейтинг от 0 до 10)
- Фильтрация по жанру и году выпуска
- Удаление фильмов из коллекции
- Автоматическое сохранение в JSON файл
- Загрузка данных при запуске программы
